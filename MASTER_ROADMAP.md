# R6 Creator AI — Unified Personal Version 1 Master Roadmap

## Authoritative product direction

R6 Creator AI is one private, local-first application with two primary
workspaces: **Creator Studio** and **Coaching Lab**. The primary visual input is
an owned gameplay screen recording. A Match Replay is optional structured
evidence. A permitted local/YouTube reference or Creator Style Profile is
optional structural guidance.

The application supports recording-only, replay-only, combined
recording-and-replay, recording-and-reference, and the full
recording/replay/reference workflow. It never fills missing replay data with
plausible-looking pixels, audio, camera motion, or tactical facts. Direct
observations, replay facts, inferences, conflicts, user-confirmed context, and
unknowns remain separate.

## Preserved replay capability boundary

The integrated MIT provider recovers stable header, team, player, operator,
score, and match-feedback fields. A genuine nine-round `Y11S2_Alpha04` package
also completed through the corrected provider. It does not expose
validated positions, orientation, stance, health, weapons, ammunition, shots,
damage, gadgets, reinforcements, drones, destruction, or a player-view camera.
Match Replay files also do not contain original gameplay pixels or audio.

The second audited parser compiles and produces richer output on that fixture,
but its checkout has no license file. It remains audit-only and is not copied,
integrated, or distributed.

Unsupported rich fields remain visibly unavailable. U2 may synchronize only
facts actually exposed by a selected replay with observations actually measured
from a selected recording.

## Definition of Personal Version 1

Version 1 requires the complete gates in the authoritative unified execution
prompt: real recording-based visual workflows, optional replay synchronization,
short- and long-form playable exports, local voiceover, evidence-backed coaching
reports, safe storage/deletion, cancellation/retry/restart recovery, passing
automated/build/browser verification, a clean Git state, and a verified release
tag. An interface, fixture, plan, or database schema alone is not completion
evidence.
