Browser studio

Open a recording up to 4 GiB / 6 hours. Individual exports are limited to five minutes and 256 MiB, at up to 1920 pixels on the longest side and 30 fps.

Compatible WebCodecs support is required. Keep the original and a downloaded project backup; browser storage can be cleared.

Full local app

Native FFmpeg editing with a configured 20 GiB source limit, local storage and optional transcription/replay tools.

A real 8.39 GB import and a 12-second 1080p/60 clip were verified here. These results apply to the local app, whose advanced tools run on your computer.

What the real-recording review improved

Large native imports now pass through the framework without a truncated copy. Writing controls also keep native server tools outside the browser page.

The local review checked import identity, range validation, playback, clip download and saved work after a clean restart. Full source decoding finished with a timestamp warning; the selected clip decoded cleanly. Visual inspection used timeline samples and selected playback.

400 source tests passed. A hand-selected moment and passing software checks do not establish automatic gameplay-recognition accuracy. Browser and local editor capabilities remain separate.
